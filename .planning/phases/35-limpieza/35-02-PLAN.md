# 35-02 PLAN — Retirar la API deprecada (CLOSE-02, #139)

Único cambio que rompe de v2.0 (D-14, D-82). El frontend nuevo no usa nada de esto (35.1 borró al único consumidor).

1. **Endpoints que se retiran, con su reemplazo:**
   - `GET /games/{id}/results`, `GET /games/{id}/elo`, `GET /games/{id}/records`, `POST /games/{id}/achievements` → `GET /games/{id}/report`.
   - `GET /players/{id}/profile`, `GET /players/{id}/elo-summary` → `GET /players/{id}/insights`.
   - `POST /achievements/reconcile` → `POST /admin/recompute`.
2. **Campos que se retiran:**
   - `emoji` y `record` de `GET /records`;
   - `icon` y `fallback_icon` de los logros. Sale el tercer argumento de cada `AchievementDefinition`.
3. **Código que queda sin uso y se borra:**
   - `services/record_calculators/`, `game_records_service`, `player_records_service`, `player_profile_service`;
   - `helpers/records`, `models/record_comparison` y `record_entry`;
   - schemas `game_records`, `player_profile` y `elo_summary`, y `record_comparison_mapper`;
   - `EloService.get_summary_for_player` y los métodos de repositorio que solo usaba;
   - `GamesService.get_game_results`, `reconcile_all` y `GameListItemDTO`.
4. **Tests:**
   - El golden compara posiciones y ELO por partida contra el informe; el replay completo, contra el historial guardado.
   - Los co-poseedores (D-05, D-17) se prueban sobre el motor v2.
   - Los 404 apuntan a `report` e `insights`, y un test nuevo confirma que lo retirado responde 404/405.
   - El e2e de la API usa el informe y la ficha.
5. **Docs:** README del backend (Fase 35.2), skills `new-record` y `new-achievement`.
